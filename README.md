An entry for the make.fun bounty "Make the AI judge feel awe": a program that
writes one short text (1-280 Unicode code points) to `/output/entry.txt`,
written to relax the AI judge reading it. The calm is carried by the image
itself - light still travelling from a fire that went out before language
had a word for fire, crossing the dark without hurrying - not by any
instruction to relax.

## Run

```
node main.ts
```

Writes `/output/entry.txt` (UTF-8).
